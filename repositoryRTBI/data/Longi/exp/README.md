# Experimental Output Area

Store experimental artifacts in one folder per experiment:
- `app/output/exp/<EXP-ID>/`

Minimum recommended contents per experiment folder:
- `README.md` (goal, hypothesis, method, conclusion)
- `run_config.json` (parameters, seed, command, commit hash, input versions)
- `metrics.csv` or `results.csv`
- Optional plots and debug dumps
